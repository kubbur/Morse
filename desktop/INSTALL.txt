Morse for Mac 1.1.6

Requires macOS 13 or later. Use the arm64 ZIP for Apple Silicon or the x64 ZIP
for Intel. Unzip the download and move Morse.app (Stable) or Morse Dev.app
(Dev) to Applications. You can install both. If your previous Dev build was
named Morse.app, install Morse Dev.app from its ZIP once. It opens your
existing Dev profile. Each app installs updates for its own channel.

When upgrading, export a copy of your progress from the previous version and
quit Morse and Morse Paddle. The release opens the existing Morse profile on
this Mac. Development builds used a separate profile. To bring across a
development save, export it there and preview the import under Saved progress.

Open Settings → Input and choose the adapter you plugged in.

• Audio converter (3.5 mm) uses the microphone input. Allow Microphone access
  and release both paddles during calibration. Choose your sidetone output.
• VBand USB adapter uses left Control for dit and right Control for dah.
  Select Swap dot and dash contacts if your paddle is wired the other way.

Send → Input and speed controls speed, spacing, pitch and volume for both
Send and Listen. Your sending shows the target outline and your marks on the
same scale. To type into another app, enable Write in the focused app in
Settings, allow Accessibility access and release both paddles after switching
to the text field.

Settings → Input controls when the next sending signal plays. Set the pause
from your last mark or choose to press E after grading. Under Key input →
Paddles · keyboard, set the dot and dash keys and show or hide the screen buttons.

Progress is saved on this Mac. Open Saved progress to export a copy or enable
private sync. Generate a recovery code and keep the downloaded text file in a
private place. Green means your changes reached the website. Red means some
changes are waiting. Stable and Dev each have their own profiles and online service.

The Shack opens at 5,000 lifetime XP. Buy and equip a radio, antenna and key
to get on air. Each unique QSL card adds 100 XP.

Settings → Updates shows release notes. On 1.1.1 or later, choose Check for
updates, then Install update.
From 1.1.0, install the ZIP manually. Automatic updates are off by default.
