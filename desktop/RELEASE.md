## What’s new in Morse 1.1.4

- Perfect timing feedback appears when you release the last mark of an exercise. The sending display clears for the next exercise or retry. In **Settings → Input → Pause after your last mark**, you can set the wait from 0.5 to 15 seconds, including when practising with slow spacing.
- Send remembers your chosen spacing speed when you change sending speed. If you slow down below your spacing setting, Morse uses standard spacing until you speed up again.
- **Progress → Practice sessions** shows your latest Listen and Send sessions together. Six sending badges recognise clean sends, sending a group, completing the alphabet and reaching 1,000 characters. Existing sending progress counts toward the badges.
- The leaderboard shows your public XP alongside your total XP. Changing score sharing for a saved callsign takes effect immediately. Turning it on shares eligible results earned from then on.

## Install or update

From Morse 1.1.1 through 1.1.3, open **Settings → Updates → Check for updates**, then choose **Install update**. For a first install or an upgrade from 1.1.0, download the ZIP for your Mac, quit Morse and move the unzipped **Morse.app** to Applications. Both builds require macOS 13 or later.

[Apple Silicon download](https://github.com/kubbur/Morse/releases/download/morse-v1.1.4/Morse-1.1.4-mac-arm64.zip) · [Intel download](https://github.com/kubbur/Morse/releases/download/morse-v1.1.4/Morse-1.1.4-mac-x64.zip)

Both downloads use ad hoc signing. If macOS asks for approval when opening a manual download, follow [Apple’s instructions](https://support.apple.com/en-us/102445).

## Progress and rollback

Use **Saved progress → Export progress** to keep a copy before upgrading. To return to 1.1.3, export your latest progress, turn off automatic updates, quit Morse and reinstall the previous build for your Mac. [Morse 1.1.3 downloads](https://github.com/kubbur/Morse/releases/tag/morse-v1.1.3)

The website ZIP contains the browser trainer, server and Docker build files for a separate deployment. [Website update ZIP](https://github.com/kubbur/Morse/releases/download/morse-v1.1.4/Morse-1.1.4-web.zip)
