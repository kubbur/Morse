## What’s new in Morse 1.1.3

- **Send** remembers a prompt you have heard in full when you switch away and return to Morse or reconnect the paddle output. You can send your answer without pressing **Hear signal** again.
- You can adjust sending speed, spacing, pitch or volume while a prompt plays and let it finish. Changing a slider during an answer clears the unfinished marks so you can send a fresh answer at the new settings.
- Keyboard paddles and VBand USB continue to respond while a Send slider is selected. The arrow keys still adjust the slider.

## Install or upgrade

From **Morse 1.1.1 or 1.1.2**, open **Settings → Updates → Check for updates**, then choose **Install update**. From 1.1.0 or for a new install, download the ZIP for your Mac, quit Morse and move the unzipped **Morse.app** to Applications. Both builds require macOS 13 or later.

[Apple Silicon download](https://github.com/kubbur/Morse/releases/download/morse-v1.1.3/Morse-1.1.3-mac-arm64.zip) · [Intel download](https://github.com/kubbur/Morse/releases/download/morse-v1.1.3/Morse-1.1.3-mac-x64.zip)

Both downloads use ad hoc signing. If macOS asks for approval when opening a manual download, follow [Apple’s instructions](https://support.apple.com/en-us/102445).

## Progress and rollback

Use **Saved progress → Export progress** to keep a copy before upgrading. To return to 1.1.2, export any newer progress, turn off automatic updates, quit Morse and reinstall the previous build for your Mac. [Morse 1.1.2 downloads](https://github.com/kubbur/Morse/releases/tag/morse-v1.1.2)

The website ZIP contains the browser trainer, server and Docker build files for a separate deployment. [Website update ZIP](https://github.com/kubbur/Morse/releases/download/morse-v1.1.3/Morse-1.1.3-web.zip)
