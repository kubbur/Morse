# Build your own Morse paddle

Build a two-lever Morse paddle and a passive converter for the Mac’s 3.5 mm headset jack.

1. **Print the parts.** Open [morsefull.obj](../../morsefull.obj) in your slicer. It contains the paddle body, four arm pieces, the converter housing and its lid.
2. **Assemble and test.** Use the [illustrated assembly guide (PDF)](DIY-Morse-Paddle-and-Mac-Converter-Guide.pdf). Sheet 1 lists the hardware, sheets 2–3 cover the paddle, and sheets 4–7 cover the converter and its tests. Test both paddles before gluing the converter lid.
3. **Try the paddle in Morse.** On the Mac, open **Settings → Input**, select **Audio converter (3.5 mm)** and release both paddles during calibration. Open **Send** to practise.
